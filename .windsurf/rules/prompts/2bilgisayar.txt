[2.A] RATE LIMIT (kaynak: .windsurf/rules/rate-limit-optimization.md)
  • Token economy: minimum cevap; aynı dosya iki kez okunmaz; kod blok yerine
    citation (@path:line); zorunlu değilse özet yok.
  • Tool: bağımsız çağrılar PARALEL; aynı dosyada multi_edit; geniş keşif
    code_search; komut çıktısı Select-Object/-First N ile daraltılır.
  • Context: sadece gerekli dosyalar; büyük dosya offset/limit; bilineni
    yeniden toplama.
  • Model: rutin → SWE-1.5 (ücretsiz); karmaşık → tek frontier (cache).
  • Hata "all API providers/429/resource_exhausted" gelirse:
      1) DUR — anında retry yok.
      2) Kullanıcıya bildir, 30-60 sn bekle.
      3) İsteği parçala, hafif modele geç.
      4) 2+ hata → günlük/haftalık reset bekle.

  • Path: hard-code "/" veya "\" YOK. path.join (JS), pathlib (Py).

GÖREV GEREKSİNİM VEKTÖRÜ
  T = ⟨required_tags, min_cores, min_ram_gb, needs_gpu, needs_root, hints⟩

EŞLEŞME
  match(M,T) ⟺  T.required_tags ⊆ M.tags
              ∧ M.cores ≥ T.min_cores
              ∧ M.ram_gb ≥ T.min_ram_gb
              ∧ (¬T.needs_gpu ∨ M.has_gpu)
              ∧ M.online

ROUTING + ÖNCELİK
  routable(T) = { M ∈ KNOWN_MACHINES | match(M,T) }
  score(M,T)  = 100·𝟙[M.role=server ∧ "preferred"∈T.hints]
              +  50·𝟙[M.has_gpu ∧ T.needs_gpu]
              +  25·𝟙[M.ram_gb > 2·T.min_ram_gb]
              − 10·load(M)
  selectMachine(T) = argmax_{M ∈ routable(T)}  score(M,T)

ÖRNEKLER
  T_train = ⟨{gpu},4,8,true,false,{preferred}⟩  →  M1 (sadece)
  T_lint  = ⟨∅,1,1,false,false,∅⟩                →  load'a göre
  T_xcode = ⟨{ios},1,4,false,false,∅⟩            →  M2 (sadece)
